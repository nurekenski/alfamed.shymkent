ОРНАТУ
1. Барлық файлдарда "alfamed.kz" сөзін нақты доменге ауыстырыңыз (VS Code / Notepad++: "Найти в файлах → Заменить").
2. Файлдарды папкалық құрылымымен хостингтің түбір папкасына (public_html) жүктеңіз.
3. Google Search Console және Яндекс Вебмастерге сайтты қосып, sitemap.xml жіберіңіз.
4. Яндекс Метрика және Google Analytics кодтарын әр беттегі "<!-- Яндекс Метрика ... -->" деген жерге қойыңыз.
