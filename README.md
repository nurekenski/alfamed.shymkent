Статический двуязычный сайт (RU — корень, KZ — папка `/kz/`).

- Адрес: г. Шымкент, пр. Тауке хана, 146
- Телефон и WhatsApp: +7 707 351 80 00

## Структура
- `index.html`, `*.html` — страницы на русском
- `kz/` — страницы на казахском
- `img/` — фото врачей
- `sitemap.xml`, `robots.txt`, `llms.txt` — SEO / GEO
- `_build/` — исходники генератора (не публикуются на GitHub Pages)

## Публикация
